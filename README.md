# ripr. — paste. rip. keep.

> Ad-free media grabber for Instagram Reels, YouTube videos, Shorts & Music.
> No pop-ups. No trackers. No sign-ups.

**Live →** https://puneethacharya71.github.io/ripr/ · **Portfolio →** https://puneethacharya71.github.io/portfolio/

![License: MIT](https://img.shields.io/badge/License-MIT-FF4D00.svg)
![Trackers](https://img.shields.io/badge/trackers-0-17150E)

## Features

- 🎬 Instagram Reels/Videos · YouTube Videos/Shorts/Music → MP4 or MP3
- ⚡ Paste anywhere (Ctrl+V) · batch queue · QR share
- 📱 PWA — installable, offline-ready, Android share-target
- 🕵️ Hidden owner console (type `admin`) — visit log + CSV export
- 🛡️ Optional Flask + yt-dlp backend → real downloads (SERVER LIVE)

## Run

**Demo:** open `index.html`. Done.

**Real downloads:**
```bash
pip install flask flask-cors yt-dlp
RIPR_KEY=my-secret python server.py
```
Then open once: `https://puneethacharya71.github.io/ripr/?api=http://localhost:8000`

## Stack

HTML/CSS/JS · zero frameworks · Flask + yt-dlp · one service worker.
